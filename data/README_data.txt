DATA DIRECTORY
==============

This directory contains observational data files and Monte Carlo outputs.

Binary/Large Data Files (not committed to git):
------------------------------------------------

fermi_lat_3fhl_catalog.fits
  - Fermi-LAT Third Catalog of Hard Sources (3FHL)
  - Download from: https://fermi.gsfc.nasa.gov/ssc/data/access/lat/
  - File size: ~50 MB
  - Format: FITS (Flexible Image Transport System)

icecube_neutrino_limits.csv
  - IceCube neutrino stacking analysis limits
  - Source: IceCube Collaboration public data
  - Format: CSV with columns [source_name, RA, Dec, flux_limit, energy_range]

auger_uhecr_spectrum.dat
  - Pierre Auger Observatory UHECR spectrum
  - Download from: https://www.auger.org/index.php/cosmic-ray-data
  - Format: ASCII table [Energy(EeV), Flux, Error]

mc_posterior_samples.h5  [LEGACY -- NOT part of the reported result]
  - Would be produced only by running the legacy MCMC module
    (code/monte_carlo_sampling.py), which is not used to obtain the
    reported (deterministic) result.
  - This file does NOT currently exist anywhere in this repository.
  - No specific sample count, chain count, or file size is established
    for it, since no specific configuration of the legacy module has
    been run and characterized in this repository; any prior "~500 MB,
    10^6 samples" figure was a planning estimate for a run that was
    never performed, not a description of an existing file.
  - If generated by running the legacy module, it would (per that
    module's own code) contain:
    - 'chain': MCMC chain (n_walkers x n_steps x n_dim)
    - 'log_prob': log probability values
    - 'acceptance': acceptance fractions
    - 'autocorr': autocorrelation times

How to Obtain Data:
-------------------

1. Fermi-LAT 3FHL Catalog:
   wget https://fermi.gsfc.nasa.gov/ssc/data/access/lat/3FHL/gll_psch_v13.fit
   mv gll_psch_v13.fit fermi_lat_3fhl_catalog.fits

2. IceCube Data:
   Download from IceCube public data releases
   Or use observational_constraints.py with built-in limits

3. Pierre Auger Data:
   Download from Auger website or use built-in parameterizations

4. Monte Carlo Samples (LEGACY, not needed for the reported result):
   Running `python code/monte_carlo_sampling.py` would generate
   mc_posterior_samples.h5 from the legacy MCMC module, but this is
   not required to reproduce the reported deterministic result, and no
   specific run of it has been characterized in this repository.

Summary -- what is actually present vs. not present:
------------------------------------------------------

- Data actually present in this directory: none (this directory
  currently contains only this README).
- Data not present, optional to download: fermi_lat_3fhl_catalog.fits,
  icecube_neutrino_limits.csv, auger_uhecr_spectrum.dat -- the code
  works without these via the built-in hardcoded parameterizations in
  code/observational_constraints.py; downloading them is optional and
  not required to reproduce the reported result.
- Legacy MCMC artifact, not present, not required: mc_posterior_samples.h5
  (see above).
- Inputs required for the reported deterministic (log10 Lambda,
  log10 m_X) inference: none beyond the existing code itself (the
  fixed benchmark, prior bounds, and validity conditions are all
  defined in code/monte_carlo_sampling.py and code/eft_cross_sections.py;
  no external data file is required to reproduce the reported result).

Git LFS (Large File Storage):
------------------------------

For version control of large files, consider using Git LFS:

  git lfs track "*.fits"
  git lfs track "*.h5"
  git add .gitattributes

Note: These data files are typically too large for standard git repos.
Store them separately or use Git LFS for collaboration.
