FIGURES DIRECTORY
=================

This directory contains all publication-quality figures in PDF format.
Figures should be generated by running the corresponding Python scripts in ../code/

Figure List:
------------

fig1_eft_validity_corrected.pdf
  - EFT validity cutoff analysis (regenerated with corrections)
  - Shows cutoff scale vs UHDM mass
  - Generated by: code/eft_cross_sections.py

fig2_gamma_max.pdf
  - Maximum Lorentz factors from GRMHD simulations
  - Shows γ_max vs magnetization parameter σ
  - Generated by: code/grmhd_acceleration.py

fig3_production_rate.pdf
  - UHDM production rates as function of mass
  - Parton-level quantities using the current exploratory parametric quark-antiquark PDF/luminosity stand-in; not CT18 NNLO and not benchmarked or validated against a real PDF set
  - Generated by: code/pdf_integration.py + code/eft_cross_sections.py

fig4_constraints.pdf
  - Multi-messenger constraints combined plot
  - Fermi-LAT, IceCube, and Pierre Auger limits
  - Generated by: code/observational_constraints.py

figS1_mcmc_diagnostics.pdf
  - MCMC convergence diagnostics (supplementary material)
  - Corner plots and trace plots from emcee
  - Generated by: code/monte_carlo_sampling.py

Notes:
------
- All figures use matplotlib with publication settings (Nature/ApJ style)
- PDF format ensures vector graphics for lossless scaling
- Color schemes are colorblind-friendly
- Run workflow/run_analysis.sh to regenerate all figures
